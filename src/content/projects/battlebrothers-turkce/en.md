Battle Brothers is a turn-based strategy game about running a mercenary company. Its text does not live in a separate data file but inside compiled scripts, so the real work was finding those strings and writing them back safely.

I prepared fonts with Turkish glyphs, solved the file replacement mechanism, and ran the translation through markup, terminology and style checks. The patch is free and open source.
