# pandomentall.github.io

Personal CV and portfolio of Ender Aygün — software and game developer.
Turkish and English. Built with [Astro](https://astro.build), hosted on GitHub Pages.

- `/cv` · `/en/cv` — CV, also downloadable as PDF (generated from the same data at build time)
- Projects, games, blog — coming soon

```bash
npm install
npx playwright install chromium   # for the PDF step
npm run dev                       # local dev server
npm run build                     # site + CV PDFs into dist/
```
